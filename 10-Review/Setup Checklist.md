# Setup Checklist

Use this order.

- [ ] Create/open this vault in Obsidian
- [ ] Enable core plugins:
  - [ ] Backlinks
  - [ ] Daily Notes
  - [ ] Canvas
  - [ ] Templates
  - [ ] Properties
  - [ ] Graph View
  - [ ] File Recovery
- [ ] Set Daily notes folder to `01-Daily`
- [ ] Set Template folder location to `Templates`
- [ ] Set Attachment folder to `Attachments`
- [ ] Install community plugins later:
  - [ ] Dataview
  - [ ] Templater
  - [ ] Obsidian Git
- [ ] Test one daily note
- [ ] Test one book note
- [ ] Test one concept note
- [ ] Test one project note
- [ ] Review [[Home Dashboard]]

## Recommended defaults

- Daily notes folder: `01-Daily`
- Weekly notes folder: `02-Weekly`
- Template folder: `Templates`
- Attachments folder: `Attachments`
- Git backup: enable only after you understand the vault
